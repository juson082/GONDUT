# GONDUT — Play Console 입력 초안

앱 이름: GONDUT
패키지 ID(제안): app.gondut.memo

패키지 ID는 Play Console의 사용 가능 여부를 확인해야 하며, 첫 업로드 후 변경하기 어렵습니다. 상표 사용 가능 여부는 별도 확인이 필요합니다.

짧은 설명:
생각을 기록하고, 연결하며 돌아보는 오프라인 메모 공간

상세 설명:
GONDUT은 메모와 그림을 기기에 저장하고, 생각을 나무 그래프로 정리하는 기록 공간입니다.

- 빠른 메모 작성과 자동 저장, 검색
- 노드를 자유롭게 배치하고 연결해 생각 정리
- 메모와 그래프에 손글씨와 그림을 원본 그대로 저장
- 가지와 그림 위를 돌아다니는 소인 캐릭터
- JSON 파일로 메모와 그래프 백업 및 복원

인터넷 계정과 클라우드 동기화 기능은 제공하지 않습니다.

카테고리 후보: 생산성. 광고: 현재 코드에 광고 SDK 없음. 접근 제한: 로그인 기능 없음. 대상 연령, 데이터 보안 및 기타 정책 항목은 실제 사용과 개발자 계정 정보를 확인하고 제출자가 직접 입력하세요. 앱에 내장된 라이브러리와 배포 방식까지 검토하지 않은 자동 확정 답변은 제공하지 않습니다.

릴리스 노트 후보:
메모와 그래프에 손글씨와 그림을 남기고, 소인 캐릭터와 함께 생각을 정리해 보세요.

확정된 스토어 이미지: store-final/ (아이콘, 그래픽 이미지, 소개 화면 6장). 소개 화면은 앱을 예시 데이터로 렌더링한 합성 이미지이므로 실제 기기 화면과 비교해 확인하세요.
