# GONDUT 비공개 테스트 진행 순서

1. Play Console에 등록할 앱 이름 `GONDUT`과 패키지 ID `app.gondut.memo`를 확인합니다. 이 ID의 사용 가능 여부는 Play Console에서 확인해야 하며 첫 업로드 후 변경할 수 없습니다.
2. 업로드용 서명 키는 `private/gondut-upload.jks`, 암호는 `private/upload-key-password.txt`에 보관합니다. 키 별칭은 `gondut-upload`입니다. 두 파일을 안전한 위치에 따로 백업하고 공개하거나 공유하지 마세요. 같은 Play 앱의 업데이트에도 동일한 업로드 키를 사용해야 합니다.
   새 버전을 Android Studio에서 빌드할 때는 Build > Generate Signed Bundle / APK > Android App Bundle에서 이 키 파일과 별칭을 선택하고, 저장된 동일한 암호를 키 저장소와 키 암호에 사용합니다. 앱 버전 코드는 업로드할 때마다 올려야 합니다.
3. Play Console에서 앱을 생성하고 비공개 테스트 트랙에 `GONDUT-0.1.0-closed-test.aab`를 올립니다. 테스터의 Google 계정 이메일을 목록에 넣고 출시를 시작한 뒤 제공되는 참여 링크로 설치합니다. 앱 설정과 심사에 필요한 나머지 항목도 완료합니다.
4. 설치 후 메모 작성·종료 후 재실행, 한글 검색, 그래프 노드 배치·이동·연결·삭제, 백업 파일 저장과 복원을 시험합니다. 복원은 기존 데이터를 교체하므로 시험용 데이터로 진행하세요.
5. 비행기 모드에서 마이크 권한 허용, 짧은 한국어/영어 녹음, 전사문 원문 보관, 잘못 들은 경우 수정, 명시 명령과 중복 노드의 미분류 처리, 초안 확인을 시험합니다. 인식 결과와 처리 시간은 기기와 발화에 따라 달라집니다.
6. 기기의 여유 저장 공간을 확인하고 AI 초안 생성, 앱을 껐다 켠 후 초안 유지, 초안 수정 후 저장과 기존 노드 연결을 시험합니다. 5분 이내 긴 녹음에서는 25초 경계의 누락과 반복을 확인합니다. AI 분류는 항상 원문과 비교하세요.
7. 음성 원문에 `게임 트리의 NPC 노드 아래: ...`처럼 명확한 위치가 들어갈 때 초안 연결을 확인합니다. 같은 이름의 트리 또는 같은 트리 안의 부모 노드를 추가해 중복되는 경우에는 자동 연결하지 않는지도 확인합니다. 현재 구두점이 실제 전사에 어떻게 나타나는지와 언어별 성공률은 미검증입니다. 생성된 제목이 원문에 있는 표현인지, 원문 수정 후 부적절한 제목이 지워지는지도 확인합니다.

개인정보 처리방침은 `privacy-policy-draft.md`를 실제 운영자와 연락처에 맞게 검토·수정한 뒤 접근 가능한 HTTPS 웹페이지에 게시해야 합니다. Play Console 정책 항목은 실제 앱과 계정 정보를 기준으로 직접 답변하세요. 스토어 화면 캡처는 실제 앱에서 촬영하세요.

참고: 2023-11-13 이후 생성된 개인 개발자 계정은 정식 출시 신청 전 비공개 테스트에 최소 12명이 연속 14일 이상 참여해야 합니다. 이는 비공개 테스트를 시작하기 위한 조건이 아니라 정식 출시 신청 요건입니다. https://support.google.com/googleplay/android-developer/answer/14151465
