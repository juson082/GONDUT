# GONDUT

Android 우선의 로컬 퍼스트 메모 앱입니다. 메모, 손글씨, 나무 그래프와 AI 초안은 기기에 저장하며, 계정이나 외부 AI API는 사용하지 않습니다.

## 개발 환경

- Flutter, Android Studio와 Android SDK를 설치합니다.
- 저장소를 내려받기 전에 Git LFS를 설치하고 `git lfs install`을 실행합니다. 오프라인 음성 인식과 AI 모델은 Git LFS로 관리합니다. 모델 파일은 수백 MB이므로 내려받는 데 시간이 걸릴 수 있습니다.
- Android Studio에서 프로젝트를 열고 Flutter 의존성을 설치한 뒤 Android 대상으로 빌드합니다.
- Google Play에 기존 앱의 업데이트를 올릴 때는 `pubspec.yaml`의 버전 코드를 올리고 기존 업로드 키로 서명합니다. 서명 키와 비밀번호는 저장소에 포함하지 않습니다.

## 주요 기능

- 서식과 자동 저장을 지원하는 메모, 기기 저장, 백업과 복원.
- 손글씨 원본 저장, 기기 내 글자 인식 및 결과 확인.
- 메모 안의 자유 배치 나무 그래프. 빈 공간을 두 번 눌러 노드를 추가하고, 길게 눌러 이동하거나 연결과 모양을 바꿀 수 있습니다.
- 기기 내 음성 전사와 AI 과정 초안. AI가 만든 초안은 확인 후 나무에 추가할 수 있습니다. 음성 원문과 기존 가지는 보존됩니다.
- 한국어, 영어, 일본어, 중국어, 스페인어 UI 및 선택 가능한 파스텔 테마.

## 확인 사항

음성 인식과 AI 추론 품질, 기기별 속도 및 손글씨 인식률은 실기기에서 확인해야 합니다. 이미지·파일 첨부, PDF 편집과 클라우드 동기화는 제공하지 않습니다. JSON 백업은 암호화되지 않으며 녹음 파일은 포함하지 않습니다.
