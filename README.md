# GONDUT

Android 우선의 로컬 퍼스트 메모 앱입니다. 메모, 손글씨와 나무 그래프를 기기에 저장하며, 계정이나 외부 AI API는 사용하지 않습니다.

## 개발 환경

- Flutter, Android Studio와 Android SDK를 설치합니다.
- Android Studio에서 프로젝트를 열고 Flutter 의존성을 설치한 뒤 Android 대상으로 빌드합니다.
- Google Play에 기존 앱의 업데이트를 올릴 때는 `pubspec.yaml`의 버전 코드를 올리고 기존 업로드 키로 서명합니다. 서명 키와 비밀번호는 저장소에 포함하지 않습니다.

## 주요 기능

- 서식과 자동 저장을 지원하는 메모, 기기 저장, 백업과 복원.
- 손글씨와 그림 원본 저장, 획 되돌리기 및 다시 실행.
- 메모 안의 자유 배치 나무 그래프와 그리기. 첫 노드는 빈 화면을 눌러 만들고, 이후 빈 공간을 두 번 눌러 노드를 추가합니다.
- 노드와 가지, 그려진 획을 따라 움직이는 소인 캐릭터.
- 한국어, 영어, 일본어, 중국어, 스페인어 UI 및 선택 가능한 파스텔 테마.

## 확인 사항

이미지·파일 첨부, PDF 편집과 클라우드 동기화는 제공하지 않습니다. JSON 백업은 암호화되지 않습니다.
