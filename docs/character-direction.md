# 소인 캐릭터 방향

- 사용자가 직접 그린 캐릭터 그림을 받은 뒤 그 그림을 바탕으로 캐릭터와 애니메이션을 제작한다.
- 동시에 표시되는 소인은 최대 5마리다. 기록 또는 그래프의 크기에 따라 소인이 조금씩 나타날 수 있다.
- 캐릭터는 그래프 내용과 노드 위치, 연결을 변경하지 않는다. 글이나 조작을 가리지 않고 필요하면 비켜난다.
- 설정에서 캐릭터 연출을 끌 수 있도록 한다. 소리와 진동은 필수가 아니다.
- 노드 생성, 이동, 그래프 축소, 글쓰기 중 휴식 등에서 짧고 부드러운 반응을 고려한다.
- 캐릭터 그림이 아직 없으므로 임의의 소인 이미지나 설정 화면은 추가하지 않는다.
